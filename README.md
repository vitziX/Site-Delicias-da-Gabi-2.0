# Delícias da Gabi

Site institucional da **Delícias da Gabi**, doceria artesanal em Itapetininga.

## Estrutura

- `index.html` — página principal do site (HTML + CSS + JS em um único arquivo)
- `hero-pascoa.png` — imagem de destaque usada na seção principal
- `Dona do delicias da gabi.png` — foto da proprietária
- `video-delicias.mp4` — vídeo institucional

## Como visualizar localmente

Basta abrir o arquivo `index.html` diretamente no navegador, sem necessidade de servidor ou build.
